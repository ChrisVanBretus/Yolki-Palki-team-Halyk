# Yolki-Palki Project

## Описание
Проект Yolki-Palki представляет собой приложение, которое управляет eSIM-профилями, подписчиками и тарифами. Он включает в себя консольные команды для управления Docker-контейнерами, а также API для взаимодействия с клиентами.

## Структура проекта
- **Console/**: Содержит команды консоли для управления приложением.
- **DTO/**: Содержит классы объектов передачи данных (DTO) для eSIM, подписчиков и тарифов.
- **Http/**: Содержит контроллеры, middleware и запросы для обработки HTTP-запросов.
- **Models/**: Содержит модели, представляющие данные в базе данных.
- **Providers/**: Содержит провайдеры для регистрации сервисов и зависимостей.
- **Repositories/**: Содержит классы для взаимодействия с данными.
- **Services/**: Содержит бизнес-логику приложения.
- **config/**: Содержит конфигурационные файлы приложения.

## Установка
1. Клонируйте репозиторий:
   ```
   git clone https://github.com/Yolki-Palki-team-Halyk.git
   ```
2. Перейдите в директорию проекта:
   ```
   cd Yolki-Palki-team-Halyk/app
   ```
3. Установите зависимости:
   ```
   composer install
   ```

## Настройка
Настройте файл конфигурации `config/app.php` в соответствии с вашими требованиями, включая настройки базы данных и параметры API.

## Использование
Для запуска приложения используйте консольные команды, например:
```
php artisan app:docker-up
```
